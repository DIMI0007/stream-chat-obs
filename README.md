# Stream Chat OBS

**Чаты Twitch и YouTube в одной панели OBS.** Интерфейс работает локально и не требует нашего сервера. [English](docs/README_EN.md).

![Stream Chat на русском — тестовый интерфейс](docs/screenshots/chat-ru.png)

*Снимок интерфейса 0.3.9 сделан в изолированном тестовом окружении. Он показывает внешний вид, а не подключение к реальным каналам.* [English interface](docs/screenshots/chat-en.png).

## Что проверено

- Плагин загружается в OBS 33 на Windows x64; вход в Twitch и получение реальных сообщений проверены в OBS.
- Вход в Google через браузер подтверждён. Чтение и отправка сообщений YouTube во время настоящего эфира ещё требуют проверки.
- Версия 0.3.9 собирается и проходит автоматические тесты. Переключение языка, онлайн-зрители и автопоиск эфира добавлены в код; их работу на реальном эфире предстоит подтвердить.

## Возможности

- Сообщения обеих платформ в одной панели с логотипом и цветовым акцентом источника.
- Вход через браузер, без ручного копирования токенов. Учётные данные хранятся на этом ПК и защищены Windows.
- Автоматический поиск чата YouTube после запуска эфира.
- Счётчики сообщений и зрителей во время эфира. Зрители Twitch обновляются примерно раз в 30 секунд, YouTube — раз в минуту, когда API возвращает число.
- Отправка текста в выбранные подключённые каналы. По умолчанию выбраны обе платформы.
- Кнопка ⚙ в правом верхнем углу открывает настройку языка: **Авто / Русский / English**.

## Установка

1. Закройте OBS.
2. [Скачайте архив последней успешной сборки](https://github.com/DIMI0007/stream-chat-obs/actions/workflows/build-windows.yml).
3. Скопируйте всю папку `stream-chat-obs` из архива в `C:\ProgramData\obs-studio\plugins\`. При обновлении замените папку целиком.
4. Запустите OBS и откройте панель **Stream Chat**.

Поддерживаемая тестовая конфигурация: **OBS 33.0.0, Windows x64**. Архив пока не подписан цифровой подписью. Версия и ревизия исходников находятся в `BUILD_INFO.json`.
