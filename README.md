Нативный док OBS для чтения чатов и отправки сообщений в свои каналы. Плагин работает локально, без нашего сервера. Тестовая версия **0.3.0** включает адаптеры Twitch и YouTube; проверка на реальных аккаунтах ещё продолжается.

[Тестовые сборки Windows](https://github.com/DIMI0007/stream-chat-obs/actions/workflows/build-windows.yml) · [Английская инструкция](docs/README_EN.md)

## Статус готовности

| Часть | Состояние |
| --- | --- |
| Док OBS | DLL для OBS 33 собрана в Windows CI. |
| Приложение Twitch | Публичный клиент зарегистрирован и проверен в консоли разработчика. |
| Вход и чат Twitch | Код написан: вход по коду, EventSub, получение сообщений и удалений, отправка в свой канал. Сборка прошла CI; реальный аккаунт ещё не проверен. |
| YouTube | Вход через браузер, поиск активного эфира, потоковое чтение, удаление сообщений и отправка текста реализованы. Сборка и проверка протокола прошли CI; реальный аккаунт ещё не проверен. |
| Защита токенов | Windows DPAPI, повреждённый файл, локальный OAuth и формат потоковых сообщений прошли CI. |
| Подпись Windows | Артефакты пока не подписаны. Загрузка при включённом Smart App Control не гарантируется. |

Это **тестовая сборка**, а не готовый публичный выпуск. Успешный CI подтверждает сборку и перечисленные тесты, но не чтение настоящего чата.

## Как устроен лёгкий режим

- Интерфейс на Qt внутри OBS, без встроенной браузерной страницы.
- Не более 500 сообщений в истории панели; история не записывается на диск.
- Сообщения добавляются небольшими пакетами. Аватары и удалённые изображения не загружаются.
- При скрытии дока сетевые соединения и таймеры останавливаются.
- Twitch получает события через WebSocket, YouTube — через официальный потоковый API по HTTP/2 без постоянного REST-опроса.
- Повторная отправка текста после неопределённой ошибки выполняется только пользователем.
- Учётные данные сохраняются на этом ПК с защитой Windows. В CI нет пользовательских токенов.

## Установка и обновление

Проверяемая конфигурация: **Windows x64, OBS 33.0.0, Qt 6.11.1**.

1. Полностью закройте OBS.
2. Скачайте артефакт последней успешной сборки и распакуйте ZIP.
3. Скопируйте всю папку `stream-chat-obs` в `C:\ProgramData\obs-studio\plugins\`.
4. При обновлении замените папку целиком: нужны также файлы WebSockets и TLS.
5. Запустите OBS и откройте док **Stream Chat**.

Номер версии виден в панели, сведения о сборке — в `BUILD_INFO.json`. Чтобы удалить плагин, закройте OBS и удалите установленную папку `stream-chat-obs`. Локальные настройки хранятся отдельно.

## Twitch

Нажмите **«Войти в Twitch»**. Плагин откроет официальный сайт и покажет код входа. Проверьте разрешения и подтвердите доступ к вашему аккаунту. После входа используется чат своего канала.

Запрашиваются `user:read:chat` и `user:write:chat`. В DLL хранится публичный Client ID; секрет приложения не требуется. Токен проверяется при подключении и каждый час активной сессии. Отключение удаляет сохранённый локальный токен; доступ приложения можно также отозвать в настройках Twitch.

Перед отправкой проверьте выбранного получателя. При неопределённом результате плагин не пересылает сообщение автоматически, чтобы не создавать дубли.

## YouTube

Нажмите **«Войти в YouTube»** и подтвердите доступ в системном браузере. После запуска трансляции нажмите **«Найти эфир»**; если найден один активный чат, плагин подключится автоматически. При нескольких эфирах выберите нужный из списка.

Используется разрешение `youtube.force-ssl`: оно требуется для чтения и отправки сообщений. Код входа возвращается на временный адрес `127.0.0.1`, а токены сохраняются на этом компьютере через Windows DPAPI. Собственного сервера авторизации нет.

Google OAuth пока работает в режиме Testing. До публичной проверки приложения войти смогут только добавленные тестовые пользователи; общая квота проекта также применяется ко всем пользователям.

## Диагностика

Для сообщения об ошибке нужны версия, commit из `BUILD_INFO.json` и безопасный текст ошибки. Не публикуйте токены, OAuth-коды и содержимое файлов аккаунта.

Сборка выполняется в GitHub Actions. Инструменты разработки на компьютере стримера не нужны. Зависимости OBS и Qt закреплены по версиям.
