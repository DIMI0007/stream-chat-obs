# Как подключить Kick

Поддержка Kick входит в Stream Chat 0.4.0. Чтение чата, вход через личное приложение, обновление входа и отправка сообщения проверены с настоящим аккаунтом Kick.

## Только читать чат

1. Откройте шестерёнку Stream Chat и включите **«Включить Kick»**.
2. Введите имя канала без ссылки, например `otmopozok1101`.
3. Нажмите **«Сохранить и подключить чат»**. На главной появится карточка Kick с зелёным значком K, а его сообщения будут в общей ленте.

Для чтения ключи и вход не нужны. Статус **«Только чтение»** означает, что чат подключён, но отправка из плагина ещё недоступна.

## Читать и отправлять

Каждый пользователь создаёт своё приложение Kick один раз. Собственный сервер не нужен.

1. Войдите в Kick и откройте [настройки приложений](https://kick.com/settings/developer). Если сайт попросит, включите двухфакторную защиту.
2. Нажмите **«Создать приложение»**. Название укажите без пробелов, например `StreamChatOBSPersonal`. Добавьте короткое описание.
3. В поле **Redirect URL** вставьте адрес целиком:

   `http://localhost:38763/kick/callback`

   Этот же адрес можно скопировать кнопкой в настройках плагина.
4. Webhooks оставьте выключенными. Выберите права **чтения канала** (`channel:read`) и **отправки в чат** (`chat:write`). Чтение профиля (`user:read`, включая email) Kick отмечает как обязательное. Другие права не нужны.
5. Ознакомьтесь с условиями разработчика Kick и создайте приложение.
6. Скопируйте **Client ID** и **Client Secret** в одноимённые поля Stream Chat. Client Secret — это секрет приложения, а не ключ трансляции. Не показывайте его зрителям и не отправляйте в сообщения.
7. Введите имя канала, сохраните и нажмите **«Войти в Kick»**. В браузере подтвердите доступ на сайте Kick.
8. После подключения включите зелёный значок Kick под лентой сообщений: он выбирает Kick для отправки. Можно выбрать несколько сервисов сразу.

Ключи и данные входа хранятся на вашем ПК в зашифрованном виде для вашей учётной записи Windows. Плагин не сохраняет email из ответа профиля. Кнопка **«Выйти на этом ПК»** удаляет сохранённый вход локально; доступ приложения можно отдельно отозвать на сайте Kick.

## Если не подключается

- Проверьте, что имя канала указано без `https://kick.com/`.
- Для ошибки входа сравните Redirect URL с адресом выше, включая порт и окончание `/kick/callback`.
- Если порт 38763 занят, закройте другое окно входа и повторите попытку.
- Ошибка отправки не запускает повторную отправку автоматически, чтобы сообщение не появилось дважды.
- Выключение Kick скрывает карточку и настройки аккаунта, останавливает подключения и сохраняет введённые данные.

Чтение использует соединение чата сайта Kick. Этот интерфейс может измениться со стороны Kick. Вход и отправка используют [официальный API Kick](https://dev.kick.com/).
