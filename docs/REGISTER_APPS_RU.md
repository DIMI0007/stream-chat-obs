# Регистрация приложений Twitch, YouTube и Kick

Приложение здесь — это запись на сайте сервиса, которая позволяет Stream Chat подключать ваш аккаунт. Дополнительную программу устанавливать не нужно.

В готовой сборке **Twitch и YouTube уже настроены разработчиком**: нажмите «Войти» в карточке сервиса. Создавать свои приложения для обычного использования этих двух сервисов не требуется.

Для **отправки в Kick** используется личное приложение каждого пользователя. Для чтения Kick достаточно имени канала.

Инструкции ниже сохраняются в репозитории и обновляются при изменении сайтов. Названия кнопок могут быть на русском или английском.

| Сервис | Где создавать | Что выбрать |
| --- | --- | --- |
| Twitch | [Консоль приложений](https://dev.twitch.tv/console/apps) → Register Your Application | Public, категория Application Integration; права чтения и отправки чата |
| YouTube | [Google Cloud](https://console.cloud.google.com/) → Google Auth platform → Clients → Create client | Desktop app; включить YouTube Data API v3 |
| Kick | [Настройки разработчика](https://kick.com/settings/developer) → Создать | Профиль, чтение канала, отправка в чат; webhooks выключены |

## Twitch

Эта часть нужна разработчику своей сборки. В текущем плагине нет полей для замены приложения Twitch в настройках.

1. Войдите в [консоль Twitch](https://dev.twitch.tv/console/apps). Подтвердите email и включите двухфакторную защиту, если ещё не сделали этого.
2. В разделе **Applications** нажмите **Register Your Application** («Зарегистрировать приложение»).
3. Заполните поля:
   - **Name** — уникальное название, например `StreamChatOBSYourName`.
   - **OAuth Redirect URLs** — `http://localhost:3000`, затем **Add**. Вход Stream Chat через код устройства не использует этот адрес; это адрес для заполнения регистрационной формы, а не callback Kick или YouTube.
   - **Category** — **Application Integration** («Интеграция приложения»).
   - **Client Type** — **Public** («Публичный клиент»). Для входа через код устройства секрет клиента плагину не нужен.
4. Выполните проверку сайта, ознакомьтесь с условиями и нажмите **Create**.
5. В списке приложений откройте **Manage** и скопируйте **Client ID**.
6. Для собственной сборки замените значение `clientId` в `src/twitch_chat.cpp` и пересоберите плагин. Один только выпуск нового Client ID не меняет приложение в установленной DLL.

Права задаются плагином при входе, а не галочками в регистрационной форме: `user:read:chat` — чтение, `user:write:chat` — отправка сообщений от вашего аккаунта. Права управления эфиром и модерации для этого не запрашиваются.

[Официальная регистрация Twitch](https://dev.twitch.tv/docs/authentication/register-app/) · [Вход через код устройства](https://dev.twitch.tv/docs/authentication/getting-tokens-oauth/#device-code-grant-flow)

## YouTube / Google

Эта часть также нужна разработчику своей сборки. В готовом плагине вход уже настроен; поля для личного приложения Google в интерфейсе пока нет.

1. Откройте [Google Cloud](https://console.cloud.google.com/). В списке проектов сверху выберите **New project / Создать проект** и задайте название.
2. В выбранном проекте откройте [страницу YouTube Data API v3](https://console.cloud.google.com/apis/library/youtube.googleapis.com) и нажмите **Enable / Включить**.
3. Откройте [Google Auth platform](https://console.cloud.google.com/auth/overview). Если предлагается **Get started / Начать**, заполните название приложения, контактный email и аудиторию. Для обычного личного аккаунта выберите **External / Внешние**. Для приложения только внутри организации Google Workspace используется **Internal / Внутренние**, если этот вариант доступен.
4. Если приложение находится в режиме **Testing / Тестирование**, в разделе **Audience / Аудитория → Test users / Тестовые пользователи → Add users** добавьте Google-аккаунт, которым будете входить в YouTube.
5. В разделе **Data Access / Доступ к данным → Add or remove scopes** найдите и добавьте:

   `https://www.googleapis.com/auth/youtube.force-ssl`

   Этот доступ используется текущим плагином для чата YouTube. На экране Google его описание шире, чем только чат: внимательно прочитайте его перед подтверждением. Доступ к почте, контактам и диску для Stream Chat не нужен.
6. Перейдите в [Clients / Клиенты](https://console.cloud.google.com/auth/clients) и нажмите **Create client / Создать клиент**. В старом виде консоли: **APIs & Services → Credentials → Create credentials → OAuth client ID**.
7. **Application type / Тип приложения** — **Desktop app / Приложение для компьютера**. Укажите название и нажмите **Create**. Не выбирайте Web application для этой реализации.
8. Сохраните **Client ID** и **Client Secret**. Не публикуйте файл с секретом в GitHub.
9. Для своей сборки замените `googleClient` в `src/youtube_chat.cpp`, а при упаковке подготовьте `data/google-oauth.json` с совпадающим `client_id` и своим `client_secret`. В GitHub Actions секрет хранится как `GOOGLE_OAUTH_CLIENT_SECRET`; Client ID в шаге упаковки тоже должен совпадать. После этого пересоберите плагин.

Адрес возврата у плагина локальный: `http://127.0.0.1:<свободный порт>/google/callback`. Для клиента типа **Desktop app** порт выбирается при входе; фиксировать порт Kick или регистрировать веб-адрес не нужно. Обычный API key не заменяет вход через Google для отправки в чат.

Для распространения своего приложения другим людям проверьте требования Google к публикации и проверке доступа. Режим тестирования и добавление тестового пользователя не равнозначны публикации для всех.

[Официальная инструкция YouTube](https://developers.google.com/youtube/registering_an_application) · [Создание клиента Google](https://developers.google.com/workspace/guides/create-credentials#desktop-app)

## Kick

1. Откройте [Kick → Настройки → Разработчик](https://kick.com/settings/developer) и нажмите **«Создать»**.
2. Название — без пробелов, например `StreamChatOBSPersonal`. Добавьте короткое описание.
3. **Redirect URL** — `http://localhost:38763/kick/callback` целиком, без замены порта и пути.
4. **Webhooks** оставьте выключенными.
5. Выберите только:
   - чтение профиля, включая email — обязательное поле Kick (`user:read`);
   - чтение информации о канале (`channel:read`);
   - отправку сообщений в чат (`chat:write`).
6. Чтение ключа трансляции, изменение канала, модерацию, подписки на события и остальные права оставьте выключенными.
7. Ознакомьтесь с условиями Kick и создайте приложение. Откройте его, скопируйте **Client ID** и **Client Secret**.
8. В шестерёнке Stream Chat включите **Kick**. Появятся настройки аккаунта и карточка на главной.
9. Введите имя канала без ссылки и оба ключа. Нажмите **«Сохранить и подключить чат»**, затем **«Войти в Kick»**. Подтвердите доступ на сайте Kick в браузере.

Личные ключи Kick сохраняются зашифрованными на вашем компьютере. Они не включаются в общую сборку плагина и не отправляются разработчику. Email из ответа профиля плагин не сохраняет.
